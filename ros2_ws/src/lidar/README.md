# Packet structure
Each packet of Lidar have structure as below:
- Header: 0xA5 0x5A (2 bytes sync) 
- Range encoding: (byte high * 256 + byte low) / 1000.0 (Unit: meter)
- Angle encoding: (byte high * 256 + byte low) / 100.0 (Unit: degress)
- Invalid point: 0xFFFF

|-----------------------------------------------------------------------------------------------------------------------------|
|    Offset    |     Size     |                                       Content                                                 |
|-----------------------------------------------------------------------------------------------------------------------------|
|   0 - 1      |  2 bytes     | Header (0xA5 0x5A)                                                                            |
|-----------------------------------------------------------------------------------------------------------------------------|
|     2        |  1 byte      | Length                                                                                        |
|-----------------------------------------------------------------------------------------------------------------------------|
|   3 - 4      |  2 bytes     | Speed                                                                                         |
|-----------------------------------------------------------------------------------------------------------------------------|
|   5 - 6      |  2 bytes     | Start Angle (:100 -> degree)                                                                  |
|-----------------------------------------------------------------------------------------------------------------------------|
|   7 - 102    |  96 bytes    | 16 points x 6 bytes (range_H, range_L, intensity)                                             |
| ----------------------------------------------------------------------------------------------------------------------------|                                                                 
|   105 - 106  |  2 bytes     | End Angle (:100 -> degree)                                                                    |
|-----------------------------------------------------------------------------------------------------------------------------|
|   107        |  1 byte      | CRC8 (Checksum all bytes & 0xFF)                                                              |
|-----------------------------------------------------------------------------------------------------------------------------|
