\hypertarget{md__r_e_a_d_m_e_cn_autotoc_md66}{}\doxysection{常见问题}\label{md__r_e_a_d_m_e_cn_autotoc_md66}

\begin{DoxyEnumerate}
\item 使用不同的相机需要设置不同的video\+\_\+device参数么

不需要，该\+Node支持相机自适应，如果使用“支持相机”章节中列出的相机型号，运行时会自动适配。
\item 摄像头插拔注意事项

{\bfseries{严禁在开发板未断电的情况下插拔摄像头，否则非常容易烧坏摄像头模组。}}
\item 如遇到hobot\+\_\+sensor节点启动异常，可通过下述步骤进行问题排查：
\begin{DoxyItemize}
\item 检查硬件连接
\item 是否设置 tros.\+b 环境
\item 参数是否正确，具体参考 Hobot\+\_\+\+Sensors \mbox{\hyperlink{_r_e_a_d_m_e_8md}{README.\+md}}
\end{DoxyItemize}
\item 如遇到\+PC端ros2 topic list未识别到摄像头topic，做如下排查：
\begin{DoxyItemize}
\item 检查\+RDK是否正常pub图像

tros foxy 版本 \`{}\`{}\`{}shell source /opt/tros/setup.bash ros2 topic list \`{}\`{}\`{}

tros humble 版本 \`{}\`{}\`{}shell source /opt/tros/humble/setup.bash ros2 topic list \`{}\`{}\`{} ~\newline


输出：

\`{}\`{}\`{}text /camera\+\_\+info /hbmem\+\_\+img000b0c26001301040202012020122406 /image\+\_\+raw /image\+\_\+raw/compressed /parameter\+\_\+events /rosout \`{}\`{}\`{}
\item 检查\+PC和\+RDK网络能否ping通；
\item PC和\+RDK IP地址是否前三位相同； 
\end{DoxyItemize}
\end{DoxyEnumerate}
