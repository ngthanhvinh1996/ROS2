\hypertarget{md__r_e_a_d_m_e_autotoc_md47}{}\doxysection{FAQ}\label{md__r_e_a_d_m_e_autotoc_md47}

\begin{DoxyEnumerate}
\item Do I need to set different video\+\_\+device parameters for different cameras?

No, this Node supports camera adaptation. If you use the camera models listed in the \char`\"{}\+Supported Cameras\char`\"{} section, it will automatically adapt at runtime.
\item Notes on plugging and unplugging the camera\+:

{\bfseries{It is strictly forbidden to plug or unplug the camera module without powering off the development board, as it can easily damage the camera module.}}
\item If encountering abnormal startup of the hobot\+\_\+sensor node, follow these steps for troubleshooting\+:
\begin{DoxyItemize}
\item Check the hardware connections
\item Confirm the tros.\+b environment settings
\item Verify the parameters, refer to Hobot\+\_\+\+Sensors \mbox{\hyperlink{_r_e_a_d_m_e_8md}{README.\+md}} for specifics
\end{DoxyItemize}
\item If the PC-\/side ros2 topic list does not recognize the camera topics, troubleshoot as follows\+:-\/ Check if the RDK is publishing images normally
